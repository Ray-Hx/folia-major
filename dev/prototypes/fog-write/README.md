# 雾板写字原型

<!-- 说明 dev/prototypes/fog-write 原型的打开方式、实现、数据来源和接入 Folia 时要处理的问题。 -->

一块起雾的公交车侧窗：歌词像被手指一笔一笔写在雾上，写过的地方透出窗外行驶中的雨夜街景，过一会儿重新起雾。玻璃上有凝结水珠，笔画边缘会聚出小水珠，偶尔有水珠往下淌；车会颠簸，水珠跟着晃、大水珠被震落。

独立 HTML 原型，不依赖构建，不改 `src/` 代码。

## 打开

先生成笔顺数据（不进仓库，约 4.5 MB）：

```sh
git clone --depth 1 https://github.com/parsimonhi/animCJK.git /tmp/animCJK
cd dev/prototypes/fog-write
node tools/build-strokes.mjs /tmp/animCJK
```

也可以只下载用到的三个文件，放进同一个目录再运行：
- https://raw.githubusercontent.com/parsimonhi/animCJK/master/graphicsJaKana.txt
- https://raw.githubusercontent.com/parsimonhi/animCJK/master/graphicsZhHans.txt
- https://raw.githubusercontent.com/parsimonhi/animCJK/master/graphicsJa.txt

然后双击 `index.html`（需要 WebGL2）。没有 `strokes.js` 也能打开，但中日文会退回骨架追踪，面板里会提示。

- 内置两组示例，不放音乐，按固定节奏循环：
  - 「图标示例」：只画 emoji 对应的图标。
  - 「中文示例」：七句中文，有四句末尾带 emoji。
- 输入框：输入任意中日文 / emoji，回车就写到雾上。
- 在玻璃上按住拖动：自己用手指画。
- 快捷键：H 隐藏面板，B 颠一下，空格播放 / 暂停。
- URL 参数：
  - `?song=sample-zh&t=12&hide`：从第 12 秒开始，隐藏面板，用来截图。
  - 滑块同名参数可以直接带，例如 `&width=0.12&warp=1`。
  - `&text=...`：打开就写这一句。

### 本地测试歌曲（可选，不进仓库）

歌词和音频有版权，`data/` 和 `audio/` 已在 `.gitignore` 里。

- 放 `data/vocal-data.js`，页面会自动多出这些歌，没有这个文件也能正常打开。
- 文件格式：

```js
window.VOCAL_DATA = [{
  id: 'song1', name: '歌名', audio: 'audio/song1.mp3', timing: '逐字',
  lines: [{ t: 12.3, d: 4.5, words: [[12.3, 0.4, '字'], ...] }, { t: 18, d: 3, text: '只有逐行时间的句子' }],
}];
```

- `words` 的每一项是 `[开始秒, 时长, 文字]`。
- 没有 `words` 的行按 `text` 平均分配时间。

## 实现

### 书写

- **笔顺数据**
  - 中文、日文汉字、假名用 AnimCJK 的笔画中线，`strokes.js` 收全部 11038 个字，约 4.5 MB，按上面的步骤生成。
  - 每一笔是一条折线，带正确笔顺，用 Catmull-Rom 细分成顺滑曲线。
  - 假名数据里有落在方格外的辅助笔画（动画裁切用），抽取时丢掉。
- **图标**
  - 和商籁一样用 lucide 图标，`icons.js` 收了 17 个。lucide 本身是线稿，每个 SVG 元素按出现顺序算一笔，用浏览器沿路径取点，子路径之间的跳笔拆开。
  - 认识的 emoji 换成图标：❤ ⭐ 🌙 ☀ 🎵 ♪ 🌸 ✿ ✨ ☁ 🌧 ☂ 🐱 😊 ❄ 🍃 🪶 等。
  - 滑块「句尾顺手画图标的概率」：有的句子写完顺手画一个图标。
- **没有数据的字**（英文、数字、标点）：用字体画到 96×96 画布，Zhang-Suen 细化成骨架，追踪成折线，大致按从上到下、从左到右排笔顺。笔顺不保证对。
- **书写时间**
  - 每个字在自己的演唱时长内写完。比自然书写慢的字按自然速度提前写完；太快的字最多压缩到自然速度的 3 倍。
  - 笔与笔之间抬手停一下。
  - 一个图标的时间是普通字的 2 倍。
- **手写感**（两个滑块，默认都开）
  - 歪斜：整字转动、上下错落、整行倾斜。
  - 变形：
    - 整字斜切、横竖各自缩放，再叠一层低频弯曲。
    - 每一笔长短不一、转一点、挪一点。
    - 沿笔画有细小手抖。
  - 笔画多的字，每一笔的偏移按笔画数收小，部件位置不乱；笔画也收细（最细到 55%），不糊成一团。

### 雾和擦痕

- **擦痕遮罩**：半分辨率 2D 画布，每帧重画。每一笔画三遍（宽暗、中、窄亮），用 `lighten` 合成成边缘渐变。
- **着色器取阈值**
  - 遮罩加细噪声取阈值，所以边缘毛糙。
  - 重新起雾时遮罩整体变暗，笔画从边缘往里一片片被雾吞掉。
- **雾**：模糊的窗外加更大范围的光晕和灰白雾色，再叠浓淡起伏和细颗粒。擦开处显示清晰的窗外，擦痕边缘亮一圈（聚水）。
- **保持和起雾**：下一句开始后保持 `hold` 秒，再用 `refog` 秒重新起雾。

### 水珠

画法照搬 raindrop-fx 1.0.8（MIT）的渲染部分，模拟部分没用。

- **精灵**：用它的水珠法线贴图 `raindrop.png`，转成 data URI 放在 `sprite.js`，所以 file:// 下也能上传到 WebGL。
- **绘制**：实例化四边形画进水珠纹理，混合方式同它的 "smoother"。
- **合成**：照搬它的 `compose.glsl`。
  - 对覆盖度取 0.96–0.99 阈值成形，所以是底部略重的蛋形，挨得近的会粘在一起。
  - 按法线折射轻度模糊的窗外，加漫反射和指数 48 的高光。
  - 水珠周围一圈雾被抹掉。
- **改动一处**：水珠亮度不低于雾的一半左右（车厢灯照在水珠表面），否则在灰白的雾上像黑点。
- **三类水珠**
  - 擦痕边小水珠：沿每一笔两侧零星分布，写到哪出现到哪，起雾时变小。
  - 往下淌的水珠：少数笔画写完后出发，走走停停，走的时候拉长。身后留一道和水珠差不多宽、边缘起伏的水痕，里面零星留下小水珠。
  - 雾上的凝结水珠：下半部分略多略大，手指擦过的地方没有。

### 颠簸

默认每 3–12 秒随机一次，按 B 键手动触发。

- **车身**：先下沉再阻尼回弹，横向带一点。玻璃上的东西晃得少，窗外晃得多。
- **水珠**：所有水珠来回压扁、拉长几下。
- **震落**：越大的水珠越容易被震落，往下滑时留下水痕，水痕会重新起雾。

### 窗外

全部在着色器里程序生成，每帧按时间移动。

- **由远到近的移动速度**：楼群剪影和窗灯最慢，钠灯路灯中速，招牌和店面暖光快且带横向拖影，车灯（同向红色尾灯、对向白色前灯）最快。
- **路面和雨**：湿路面有倒影，窗外雨丝斜着往后划。
- **三个模糊半径**：同一个场景函数按三个模糊半径计算：擦开处几乎不糊，雾里糊，雾的光晕更糊。
- **车速滑块**：控制移动速度，0 就是停站。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 原型本体 |
| `strokes.js` | AnimCJK 笔画中线，`tools/build-strokes.mjs` 生成，不进仓库 |
| `icons.js` | lucide 图标 SVG 节点，`tools/build-icons.mjs` 生成 |
| `sprite.js` | raindrop-fx 的水珠法线贴图（data URI） |
| `tools/` | 两个生成脚本和中文示例句 |
| `licenses/` | AnimCJK、raindrop-fx、lucide 的授权文本 |

## 接入 Folia 前要处理的

- **授权**：AnimCJK 的 graphics 数据是 Arphic Public License，假名部分可选 LGPL，要确认能否随应用分发。raindrop-fx（MIT）和 lucide（ISC）没有问题。
- **体积**：`strokes.js` 有 4.5 MB。进应用可以：
  - 按需加载（按字分片或建索引）；
  - 或者只收常用字，生僻字退回到骨架追踪。
- **性能**：
  - 窗外每帧在着色器里算三遍（擦开处、雾、光晕），没在真实窗口里测过帧时间。
  - 擦痕遮罩每帧在 2D 画布重画后上传，进 Pixi 运行时建议改成 GPU 上画笔画。
- **英文**：骨架追踪写出来像等宽圆体，没有中日文的手写感。
- **背景**：现在窗外是程序生成的街景，接入时可以换成封面或模式自己的背景，雾、擦痕和水珠这三层不依赖背景内容。
